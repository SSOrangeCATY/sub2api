# 模型广场与实付价格查询

变体：沿用全站 standard（yellow / neutral / standard cut / contours / standard density / calm）。
主视觉：来自真实模型、分组、计费身份与价格的查询列表；不使用装饰性仪表盘。
页面类型：阅读与价格查询；桌面数据表，移动端记录行。

## 用户需要先看到什么

页面先回答“我的身份是什么”“这个模型在各分组多少钱”，默认显示折后输入、输出、缓存读取价格。顶部常驻联合搜索和可搜索的分组选择；平台用带真实条数的按钮切换，币种与计价上下文收进更多筛选。排序紧邻结果，已选条件可单独移除。切换分组时会清除不兼容的平台条件，避免把有模型的分组显示成空。标题收敛到 24–30px，控件保持至少 44px 的点击区域。

每页默认 25 条，可改为 50 / 100 条。筛选改变时回到首页，后台刷新不重置仍有效的页码。移动端同样直接提供搜索、分组和平台，次要条件按需展开。

模型发现优先采用已有渠道目录。没有销售目录的分组，从一次持久账号候选快照、账号公开映射和提供方已有默认目录发现模型，沿用真实网关的模型支持判定；只返回公开 key，不返回映射目标、账号标识或凭据。合法的上下文后缀与混合调度别名保留。空分组仍可选择并显示未配置状态，不制造模型或价格。分组名称不参与路由或币种推测；原权限过滤继续生效。

只配置账号统计成本规则、没有销售模型定价、模型映射或模型限制的渠道，同样沿用账号模型发现。其普通身份报价绕过成本规则，进货价报价才匹配账号成本规则；上游价不会因此成为全局默认价或标准售价。成本基价可在“渠道 → 账号统计定价规则”编辑，不需要改代码或重新部署。现有上游费率同步只维护账号系数，不自动同步模型基础单价；最终成本为成本卡计算结果再乘当时账号系数。

官方参考、缓存写入的独立 TTL、长上下文档位、分时调整和思考等级在每条价格的详情中展示。官方目录按 USD 展示，不能与 CNY 卡直接计算折扣。比较入口不展示需要用户自己换算的销售倍率。

## 价格语义

- 普通身份：价格卡经过用户专属或分组费率得到单价；图片与视频按已启用的独立费率处理。订阅高峰只影响 token 费率，图片按次费用不受影响。分时按配置时区、工作日范围生效。
- 无渠道普通分组使用 `kind=customer` 的逐账号中性报价，再应用用户/分组费率；候选账号长上下文开关和订阅豁免不同会形成价格范围。`kind=account_cost` 表示进货价已含账号计费系数，不再应用销售倍率。报价计算复用真实计费函数，不改动扣费规则或账号费率快照。
- 进货价身份：按实际账号采购成本规则与账号费率报价，不叠加销售倍率。自定义账号统计规则优先，其次渠道“应用模型定价到账号统计”，再到原生目录，最后使用中性的客户费用回落，遵循实际扣费优先级。不同候选线路产生数值区间，任何未确认的候选价格都不能被当作零或被其他候选的单一价格掩盖。
- 同一模型可能存在 token / 图片 / 按次等不同的采购计费方式，必须分别显示其数量单位。自定义统计视频规则实际按请求计数，因此公开价目明确标为按次。
- 自定义统计 token 档位使用输入、输出和缓存 token 总数，区间绝对替换平价字段，不继承遗漏单价、不应用销售区间倍率。未命中任何档位时继续使用保留的平价回落，价目详情披露有限区间和间隙的回落价格。
- 原生目录的进货价通过与实际采购账单相同的统一计费入口取报价快照，包含原生峰谷策略与账号的长上下文开关及订阅豁免。默认目录售价同样使用当前时点快照。快照记录报价时点，页面可见时定期刷新，过期快照不继续当作有效价格展示。
- 列表是标准服务层级的单位价目，不能代表任意请求的预先锁价；请求实际使用的服务层级、思考等级、附加搜索调用、用量与最终路由仍决定账单。未实现完整 Fast / Flex 报价选择器，本版不声称展示所有服务层级的数值报价。

## 币种与余额

source_currency 表示价格卡的数值标价币种，settlement_currency=USD 与 unit_policy=nominal 表示余额按数值记账。CNY 卡显示 ¥，USD 卡显示 $，其他已配置币种显示其代码；不会根据模型名称猜币种，也不会改变定价、余额或历史用量。

价格区标题统一放一个问号按钮，悬停、键盘聚焦或触屏点击显示说明，再次点击或 Escape 关闭。说明包含“¥0.20 的费用扣除 0.20 余额，余额页面使用 $ 符号”，明确无汇率换算；价格数字旁不重复添加问号。

## 复用入口与权限

模型广场、API 密钥列表和密钥编辑、可用渠道的模型入口复用同一套价目组件。GET /api/v1/model-prices?group_id=... 不依赖公开广场开关，但必须先通过登录和可绑定分组校验，再加载价目。个性化响应使用 private / no-store，并按 Authorization 和语言区分；账号 ID、供应商凭据、规则内部 ID 不进入公开 DTO。

进货候选遵循明确的平台边界、混合 Antigravity 开关、各平台实际模型映射及渠道模型限制。临时不可用但仍由配置允许的线路保留在范围内，防止报价承诺只走当前最低价线路。去重只由公开价格内容决定，不允许内部数据库标识或时间戳让相同价格占用多个变体。

## 验收边界

价格计算测试与实际采购费用函数对照，覆盖原生峰谷、账号倍数、平台隔离、模型限制、自定义区间、有限档尾与空洞、订阅长上下文豁免和价格去重。

前端覆盖币种、区间、独立媒体费率、无价与零价、混合单位、搜索排序分页、错误重试、请求乱序及说明交互。浏览器使用本地合成数据验收深浅主题与 375 / 768 / 1024 / 1440 宽度，并核查溢出、触控面积和 Endfield 样式。
