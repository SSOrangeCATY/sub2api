# 风控中心页面与交互规格

变体：standard（yellow / neutral / standard / contours / standard / calm）。
主视觉：已保存规则、限制用户及处置记录中的真实业务字段。
页面类型：阅读型管理工作区，沿用产品全局 Endfield 字体和令牌。

## 功能位置

安全审计下的入口命名为风控中心，路径保持 /admin/risk-control。页面内三个工作视图为内容审核、用户限制、处置记录。入口名称和页面说明覆盖用户限制，避免把处罚配置藏在审核引擎设置中。

内容审核保留引擎、范围、运行状态和已有日志。用户限制直接显示规则编辑、当前限制与解除操作。处置记录展示通用账本的历史动作和当时决策版本。

## 用户限制的阅读顺序

1. 已保存规则：配置版本、分组和模型范围、已保存的自然语言处罚说明，以及编辑范围和重新读取入口。
2. 规则草稿：独立开关、滚动窗口、逐级门槛、解除方式、暂停小时数、后果预览及保存操作。
3. 当前限制：筛选、页大小、查询时间、当前窗口次数、处置时次数、开始和解除时间，以及逐行解除入口。

分组和模型范围目前与内容审核共享，页面明确说明修改会同时影响两者。关闭规则只停止新的自动处置，不会解除已有有效限制。

保存携带预期版本。冲突与读取失败保留草稿并显示明确错误；重新读取保留未保存修改，不能把错误响应当成默认配置。切换工作视图保留草稿，离开页面有未保存保护。

## 当前限制与处置记录

基础账户状态和策略限制分别显示。临时限制展示管理员时区下的准确时间；需管理员解除时不伪造自动到期倒计时。

搜索、状态和页大小先作为草稿。应用筛选回到第一页；尚未应用的页大小不与旧游标混用。使用服务端 has_more 和 next_cursor 翻页。失败保留旧记录，旧响应不能覆盖更新后的筛选结果。

跨页遍历使用实时成员，页内查询时间用于解释数据的新旧。当前总数变化时提示刷新；不承诺第一次打开页面时的成员在整个遍历期间保持冻结。

处置记录包括命中、暂停、升级、到期、管理员解除与忽略，并展示当时次数、规则版本、操作者及原因。历史不会随解除被删除。

## 解除确认与异常路径

原生模态确认框展示用户、限制版本、影响范围、处罚方式、处置时次数与门槛、开始时间及准确期限。解除要求填写原因。基础账户另行停用时单独提示，不能把解除 API 限制表述成恢复基础账户。

提交期间防止重复操作。网络结果不明确时锁定原目标与原因，只能重试冻结的原操作。409 后读取更新版本，展示新处罚及变更提示，保留原因，等待再次确认。重新读取也同步刷新背景列表。错误版本的成功响应按未确认结果处理。

键盘焦点进入模态框，原生模态约束焦点；可取消阶段 Escape 关闭，结果不明确或提交阶段不能通过 Escape 丢弃原操作。

## 视觉约束

只有一个强调色，当前工作视图持续以强调填充标识；切角用于可操作控件。正文、列表和不可点击容器保持直角，用细线分区，不新增阴影、发光或装饰渐变。告警与待处理使用强调色和墨线，红色保留给删除。

所有交互目标至少 44 像素。原生小复选框以其可点击标签作为触控目标。浅深主题都使用全局 ef 令牌，文字不压切角，数字使用等宽数字。减少动效时内容完整且没有依赖动画的操作。

## 验证记录与范围

本地组件与工作视图交互回归覆盖规则草稿、版本冲突、解除重试、页大小与游标一致性，以及临时限制升级后重新确认。真实浏览器使用隔离的合成数据，在 375、768、1024、1440 四个宽度和浅深两套主题检查三个工作视图与解除框。

浏览器合成数据检查用于布局、焦点和交互验收；数据库迁移、并发计数、解除代际及持久化顺序另由仓储和真实 WebSocket 回归验证。上述结果不代表已经部署到生产。
